# 江城钓客 · 武汉江湖 3D 垂钓模拟

PC 端浏览器 3D 钓鱼游戏（Three.js，鼠标 + 键盘操作）。以武汉"百湖之市、两江交汇"为背景，
**台钓 + 路亚**两大钓法体系，**57 种真实分布于长江中游（武汉江段及通江湖泊）的鱼种**，
钓获后进入**图鉴 + 集卡**收集系统。全部美术（地形、水面、天空、鱼、植被）程序化生成，无需外部素材。

## 运行方式

必须通过 HTTP 服务器访问（ES Module 限制，不能直接双击 index.html）：

```powershell
# 方式一：自带脚本（Windows PowerShell）
powershell -NoProfile -ExecutionPolicy Bypass -File serve.ps1
# 方式二：任意静态服务器
npx serve .        # 或 python -m http.server 8137
```

浏览器打开 <http://127.0.0.1:8137> 即玩。存档保存在浏览器 localStorage。

## 玩法

### 台钓（悬坠浮漂）
默认 **5.4 米竿 + 齐竿线 5.8 米**（最远抛距≈竿长+线长，升级长竿才抛得远）。手持长竿细身、无轮带绕线板。
调好钓深（滚轮，钓底/离底/钓浮决定鱼种水层）→ 抛竿 → 看漂相：
- **顶漂**（上送）、**顿口**（有力下顿）、**黑漂**（拉黑）、**走漂**（横移）——真口，窗口约 1 秒，立刻左键
- 漂轻微乱颤——多半是白条麦穗闹窝，提竿空军
- 蚯蚓/红虫钓鲫鱼黄颡，玉米麦粒钓鲤草鳊，拉饵钓浅可上鲢鳙
- **打窝（G）**提升进窝速度与咬钩率；晨昏（5-8 点、17-20 点）与雨前是爆口窗口

### 路亚
默认 **1.98 米短竿 + 30 米线杯**（抛距受竿调性与线杯长度共同限制，换长线杯才能远投）。手持短粗竿、带纺车轮。
拟饵决定水层与对象鱼：米诺/VIB/亮片/铁板搜翘嘴鳡鱼（快收），德州软虫跳底钓鳜鱼鲶鱼（慢拖+空格抽停），雷蛙打水面黑鱼，微物亮片钓马口白条。攻击窗口极短，看到"一口！"立即左键。

### 遛鱼
- 张力条：收线升、鱼冲刺暴涨，**满格 0.75 秒断线**；冲刺时松开右键放线保线
- 鱼有耐力条，冲刺消耗；遛乏后收线拉近，2m 内按 **F 抄鱼**
- 线松弛太久会被拉直跑鱼；竿/轮/线档位决定收线速度与容错

### 图鉴 + 集卡
- 每条鱼生成一张**收藏卡**：卡面为该鱼 3D 模型实时快照
- **品质四档：普通白卡 → 稀有蓝卡 → 史诗紫卡 → 传说橙卡**，鱼种基础档 × 个体大小共同决定；≥95% 极限体型的巨物可直达橙卡，橙卡带流光
- **分解与合成**：钓到重复且未破纪录的卡自动分解成**鱼珠**；卡册里可手动分解换珠、消耗鱼珠把卡**合成升档**（白→蓝 5珠，蓝→紫 12珠，紫→橙 30珠）
- 图鉴按 18 个类群分页，**集齐类群可领奖励**；**成就页（A）**展示 14 个里程碑成就与每种鱼的集卡品质、单尾最大重量
- **保护鱼种**（胭脂鱼·二级 / 中华鲟·一级）钓获必须放流：奖励 + 专属传说橙卡纪念

### 季节鱼情（结合真实习性）
季节按**真实月份**（3-5 春 / 6-8 夏 / 9-11 秋 / 12-2 冬）自动切换，树冠换色，HUD 显示当前季节：
- **春**🌱 产卵季，鲫鲤鳊鳑鲏靠边爆发；刀鲚、河豚、桃花鳜的春季窗口
- **夏**☀️ 高温，黑鱼/鲢鳙/黄颡/鳝活跃，早晚出钓；鳡鱼巡游
- **秋**🍂 黄金季（全图咬口 ×1.25）：鳊鲂肥美、翘嘴炸水、青鱼深水、秋鳗洄游
- **冬**❄️ 口轻（×0.6），主钓耐寒的鲫、鳜、大银鱼
每种鱼在图鉴详情里标注季节偏好与最佳时段。**概率全程拟合**：时段不对（×0.15）、钓层不对（×0.12~0.35）、季节不合（×0.2~0.5）都只是降低上鱼概率而不是绝对钓不到——所有因子连续相乘，和真实"鱼情"一样是概率问题。

### 经济闭环
卖鱼得钱（稀有度×体重）→ 商店升级竿/轮/线/漂/拟饵/窝料、买饵料 → 装备分达标后稀有大物才咬钩；卡牌分解合成提供长线养成。

## 世界与钓点（参考武汉真实水系）

按 **M** 打开钓鱼地图，在武汉水系示意图上点击前往八大钓点，每个钓点有独立的鱼种分布与上鱼概率（地图与图鉴可查）：

| 钓点 | 类型 | 特色鱼（概率倍率） |
|---|---|---|
| 梁子湖 | 湖泊 | 团头鲂（武昌鱼）×4、鳜鱼×2.5、青鱼×2.5、鳡×2 |
| 东湖 | 湖泊 | 翘嘴×2、鲫鲤×1.6、武昌鱼/鳜×1.5 |
| 汤逊湖 | 湖泊 | 鲫鲤×2、鳊/翘嘴/草鱼×1.5 |
| 后官湖 | 湖泊 | 鳜鱼/黑鱼×2、黄颡×1.6（草洞障碍区） |
| 府河湿地 | 浅滩 | 黄颡×2.5、黑鱼/鲫×2、鳑鲏×2（夏夜黄鳝泥鳅） |
| 汉江口 | 江河 | 江团×3、鳡×2、刀鲚×2（洄游通道） |
| 青山江段 | 江河 | 铜鱼×2.5、翘嘴/鳡/江团×2（码头石堆） |
| 汉阳江段 | 江河 | 大口鲶×2、土鲶/黄颡×1.5（回水湾夜钓） |

落点决定钓点：竿抛进哪个水域就按哪里的鱼情来。未标注水域为野生钓位（默认分布）。概率还与季节、时段、天气、水层、饵料叠加计算。
- **水域按真实地理建模**：长江斜贯、汉江汇入、府河北支，梁子湖/汤逊湖/东湖/后官湖四大湖盆按真实相对位置布局，八大钓点即位于真实岸线上；支持 **T 键上船划入水中船钓**
- **时间全程与真实时间同步**（北京时间，每帧校准）；**季节按真实月份**（3-5 春 / 6-8 夏 / 9-11 秋 / 12-2 冬，树冠换色）；天气取武汉实时（Open-Meteo，每 10 分钟刷新，断网回退游戏内天气机）
- 昼夜按真实时刻：清晨 5-8 点、黄昏 17-20 点是爆口窗口，夜行鱼天黑出没
- 3D 鱼群按真实时段活动（夜行鱼天黑出没），咬钩前能看到鱼游向钓饵
- **V 键水下视角**：潜到钓点看鱼进窝咬钩全过程

## 技术

- 纯前端：Three.js r160（本地 lib/，离线可用）+ 原生 ES Modules，无构建、无依赖
- 程序化生成：值噪声地形（湖盆/河槽）、顶点波浪水面着色器（菲涅尔+日照+流水漂移）、
  天空穹顶着色器昼夜色板、18 种体型原型的参数化低模鱼（顶点着色+顶点着色器摆尾）
- 音效：Web Audio 全程序化合成（环境水声/雨声/抛竿/落水/漂相/中鱼/断线/收线棘轮/开卡/金币），零音频素材
- 卡面快照：离屏 WebGLRenderer 实时渲染鱼模→ dataURL 缓存
- 存档：localStorage（金钱/装备/图鉴/卡册自动保存；本局渔护不跨刷新）
